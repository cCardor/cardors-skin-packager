# Cardor's Skin Packager

A browser-based tool for previewing, naming, and packaging Minecraft skins.

## Use

Open `index.html` in a modern browser. Add PNG skin files, choose a naming format and skin type, then package them into a ZIP archive.

The 3D preview and ZIP creation use skinview3d and JSZip from public CDNs, so an internet connection is required for those features.
